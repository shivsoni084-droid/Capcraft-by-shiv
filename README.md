# CapCraft by Shiv

Free, open source auto captions for Reels, Shorts and YouTube. Hindi, Hinglish and 20+ languages. No login, no watermark, runs on your device.

## Use
Open the GitHub Pages link of this repo and tap **Open editor**.

## Features
Hindi / Hinglish modes, word-level timing, timeline editor, caption styles with live preview, export to video, SRT, VTT and ASS.
